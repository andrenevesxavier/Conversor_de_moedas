<p>O conversor de moedas é um desafio da plataforma Alura para o maior aprendizado de conhecimentos sobre POO e APIs, o programa é capaz de acessar cotações em tempo real, atraves da API "Exchangerate api", e retornar o valor da cotação que o usuário quiser </p>

# :hammer: Funcionalidades do projeto
- `Funcionalidade 1`: Escolha de moedas para fazer a conversão.
- `Funcionalidade 2`: O usuário digita o valor que deseja converter.
- `Funcionalidade 3`: O programa retorna com a conversão com dados atualizados em tempo real em relação ao valor de cada moeda.

## 📁 Acesso ao projeto

Para acessar o código do projeto, siga os passos abaixo:

### 📌 Pré-requisitos
- Git instalado
- Java 17 ou superior

### 🚀 Passo a passo

1. No terminal bash, clone o repositório:
```bash
git clone https://github.com/andrenevesxavier/Conversor_de_moedas.git
```
